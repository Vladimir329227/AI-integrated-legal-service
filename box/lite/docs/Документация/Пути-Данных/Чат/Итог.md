# Индекс: Чат

## Объяснение терминов

- **Conversation (разговор)** — документ в БД с полями: `model`, `messages`, `preprompt`, `rootMessageId`, `assistantId`, метаданные.
- **Message Update Stream** — построчный поток JSON-обновлений, возвращаемый сервером при генерации ответа.
- **Tools / Function Calling** — механизм, при котором модель выбирает и вызывает инструменты; результаты инструментов возвращаются в модель.
- **Web Search** — дополнительный путь, когда модель инициирует поиск в Интернете.
- **Attachments/Files** — вложения пользователя, отправляемые через `multipart/form-data`.

## Ключевые компоненты системы

- **Клиент**: `src/routes/+page.svelte`, `src/routes/models/[...model]/+page.svelte`, `src/routes/conversation/[id]/+page.svelte`, `src/lib/utils/messageUpdates.ts`, `src/lib/components/chat/*`.
- **Сервер**: `src/routes/conversation/+server.ts`, `src/routes/conversation/[id]/+server.ts`, `src/routes/api/conversation/[id]/+server.ts`, `src/lib/server/textGeneration/*`, `src/lib/server/endpoints/*`.
- **База данных**: коллекции `conversations`, `messageEvents`.

## Типы сценариев

- Текстовый диалог с/без инструментов и web search.
- Мультимодальность: файлы (FormData), разбор и передача в модель/инструменты.
- Повторы/продолжение: retry/continue с переиспользованием ветки сообщений.

## Безопасность и лимиты

- Session-based аутентификация (см. `Документация/Пути-Данных/Auth`).
- Лимиты: per-minute, до-входа (гостевой режим), per-conversation.
- Доступ к разговору — по `authCondition(locals)`.

## Файлы проекта (опорные места кода)

- Создание: `src/routes/conversation/+server.ts`.
- Отправка/генерация/стриминг: `src/routes/conversation/[id]/+server.ts`, `src/lib/server/textGeneration/*`, `src/lib/server/endpoints/*`.
- Получение: `src/routes/api/conversation/[id]/+server.ts`, `src/routes/api/conversations/+server.ts`.

## Последовательность изучения

1) Создание разговора → 2) Отправка сообщения → 3) Генерация/Инструменты → 4) Стриминг → 5) Чтение.

## Сводка системы

- **Цель**: потоковый диалог с инструментами, вложениями и строгими лимитами.
- **Результат**: быстрые ответы модели, сохранение истории, расширяемость.
- **Ключевое**: JSONL-стрим, endpoint-агностика, код-центричный подход.
