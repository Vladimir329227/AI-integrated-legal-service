# Итог по инструментам
# Общее: Инструменты чата

## Что такое инструменты

Инструменты (Tools) - расширения, которые модель может вызывать во время генерации ответа (function-calling). Поддерживаются:
- инструменты конфигурации (встроенные)
- инструменты сообщества (community tools)

## Где реализовано

- Реестр/схемы/вызов: `src/lib/server/tools/index.ts`
- Запуск и извлечение вызовов из модели: `src/lib/server/textGeneration/tools.ts`
- Включение в пайплайн генерации: `src/lib/server/textGeneration/index.ts`
- Типы: `src/lib/types/Tool.ts`
- CRUD API для community-инструментов:
  - `src/routes/api/tools/+server.ts` - POST (создание)
  - `src/routes/api/tools/[toolId]/+server.ts` - GET/PATCH/DELETE
- Выбор пользователем в настройках: `src/lib/server/api/routes/groups/user.ts`

## Список реализованных инструментов (встроенные)

- Calculator
  - ID: `00000000000000000000000C`
  - Файл: `src/lib/server/tools/calculator.ts`
  - Назначение: безопасная оценка математического выражения.
  - Вход: `equation: str (required)`
  - Выход: текст с результатом; display=false.

- Directly Answer
  - ID: `00000000000000000000000D`
  - Файл: `src/lib/server/tools/directlyAnswer.ts`
  - Назначение: принудить модель отвечать напрямую (служебный tool); on-by-default/locked/hidden.
  - Вход: нет; Выход: пустой; display=false.

- Fetch URL
  - ID: `00000000000000000000000B`
  - Файл: `src/lib/server/tools/web/url.ts`
  - Назначение: скачать содержимое веб-страницы и вернуть заголовок/текст.
  - Вход: `url: str (required)`
  - Выход: `{ title, text }`; display=false.

- Web Search
  - ID: `00000000000000000000000A`
  - Файл: `src/lib/server/tools/web/search.ts`
  - Назначение: выполнить веб-поиск и вернуть контекст/источники.
  - Вход: `query: str (required)`
  - Выход: агрегированный контекст и инструкции по цитированию; display=false.

Примечение: Эти инструменты добавляются в реестр `configTools` (см. `src/lib/server/tools/index.ts`, строки 129-131).

## Инструмент парсинга документов (Document Parser)

- ID: `000000000000000000000002` (`documentParserToolId`)
- Определён: `src/lib/utils/toolIds.ts`
- Как включается:
  - Сервер: `src/routes/conversation/[id]/+server.ts` (строки 461) -если есть PDF во входящих файлах или в истории, добавляет `documentParserToolId` в `toolsPreference`.
  - Клиент: `src/lib/components/chat/FileDropzone.svelte` (строки ~70) и `src/lib/components/chat/ChatInput.svelte` -при добавлении файлов включает инструмент в настройки пользователя.
- Реализация вызова и передачи файлов в инструменты: `src/lib/server/tools/index.ts` (обработка file input в `getCallMethod`; скачивание через `downloadFile`, определение `file-type`, загрузка `uploadFile`).

## Как выбираются и вызываются инструменты

Исходный файл: `src/lib/server/textGeneration/index.ts` (строки 76-87)
```typescript
let tools = model.tools ? await getTools(toolsPreference, ctx.assistant) : undefined; // Получаем активные инструменты
if (tools) {
  const toolCallsRequired = tools.some((tool) => !toolHasName(directlyAnswer.name, tool));
  if (toolCallsRequired) {
    toolResults = yield* runTools(ctx, tools, preprompt); // Вызов инструментов
  } else tools = undefined;                                 // Иначе отключаем
}
```

Исходный файл: `src/lib/server/textGeneration/tools.ts` (строки 186-233)
```typescript
const mappedTools = tools.map((tool) => ({ ...tool, inputs: tool.inputs.map((i)=>({...i, type: i.type === "file" ? "str" : i.type})) }));
for await (const output of await endpoint({ messages: formattedMessages, preprompt, generateSettings: { temperature: 0.1, ...assistant?.generateSettings }, tools: mappedTools, conversationId: conv._id })) {
  if (output.token.toolCalls) { calls.push(...output.token.toolCalls); continue; }              // Нативные tool calls
  if (output.generated_text) { const raw = await extractJson(output.generated_text); calls.push(...raw.map((c)=>externalToToolCall(c, tools)).filter(Boolean) as ToolCall[]); } // JSON-парсинг
}
const toolResults = yield* mergeAsyncGenerators(calls.map((call) => callTool(toolContext, tools, call))); // Параллельный вызов
```

## Безопасность и ограничения
- Лимиты на размер файлов: 10MB; фильтрация MIME на клиенте/сервере.
- Community‑инструменты вызываются через `callSpace` с IP-токеном; код Space отвечает за собственную валидацию.
- Document Parser -не config‑инструмент; служит для автоподключения обработки PDF на endpoint’ах.
