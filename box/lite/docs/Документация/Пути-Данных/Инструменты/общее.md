# Общее: Инструменты чата

## Что такое инструменты

Инструменты (Tools) — это расширения, которые модель может вызывать во время генерации ответа (function-calling) для выполнения действий: вычисления, веб-поиск, скачивание URL и т.п. Поддерживаются:
- инструменты, заданные конфигурацией (config tools)
- инструменты сообщества (community tools), создаваемые пользователями через API

## Где реализовано

- Реестр и вызов инструментов: `src/lib/server/tools/index.ts`
- Оркестрация выбора/вызова в генерации: `src/lib/server/textGeneration/tools.ts`
- Включение инструментов в пайплайн: `src/lib/server/textGeneration/index.ts`
- Типы: `src/lib/types/Tool.ts`
- CRUD API для инструментов сообщества:
  - Список/создание: `src/routes/api/tools/+server.ts`
  - Получение/обновление/удаление: `src/routes/api/tools/[toolId]/+server.ts`
- Выбор инструментов в настройках пользователя: `src/lib/server/api/routes/groups/user.ts`

## Стандартные (встроенные) инструменты

Исходный файл: `src/lib/server/tools/index.ts` (строки 18–22, 129–131)
```typescript
import calculator from "./calculator";      // Калькулятор
import directlyAnswer from "./directlyAnswer"; // Принудить модель отвечать напрямую
import fetchUrl from "./web/url";            // Загрузка содержимого по URL
import websearch from "./web/search";        // Веб-поиск
...
export const configTools = z.array(...).transform((val) => [...val, calculator, directlyAnswer, fetchUrl, websearch]); // Добавляем встроенные
```

Кратко:
- calculator: арифметика
- directlyAnswer: выключатель инструментов (говорит «ответь напрямую»)
- fetchUrl: получение контента по URL (и маппинг в вывод)
- websearch: веб-поиск (генерация запроса + источники)

## Инструменты сообщества (Community tools)

- Хранятся в коллекции `tools` в MongoDB
- Описываются схемой `editableToolSchema`
- Вызываются как Hugging Face Space через `callSpace`

Исходный файл: `src/routes/api/tools/+server.ts` (строки 11–19, 53–67)
```typescript
export async function POST({ request, locals }) {
  ...
  const parse = editableToolSchema.safeParse(body); // Валидация описания инструмента
  ...
  const { insertedId } = await collections.tools.insertOne({  // Сохранение в БД
    ...parse.data,
    type: "community" as const,
    _id: new ObjectId(),
    createdById: locals.user?._id,
    createdByName: locals.user?.username,
    createdAt: new Date(),
    updatedAt: new Date(),
    last24HoursUseCount: 0,
    useCount: 0,
    review: ReviewStatus.PRIVATE,
    searchTokens: generateSearchTokens(parse.data.displayName),
  });
  return new Response(JSON.stringify({ toolId: insertedId.toString() }), { status: 200 });
}
```

## Выбор инструментов пользователем

Исходный файл: `src/lib/server/api/routes/groups/user.ts` (строки 79–86, 100–121)
```typescript
// GET /user/settings — если у пользователя нет выбранных tools,
// подставляются config tools с isOnByDefault
{
  tools:
    settings?.tools ?? toolFromConfigs.filter((el) => !el.isHidden && el.isOnByDefault).map((el) => el._id.toString()),
}
...
// POST /user/settings — валидация что все tools существуют (в БД или среди config tools)
if (settings.tools) {
  const newTools = [
    ...(await collections.tools.find({ _id: { $in: settings.tools.map((toolId) => new ObjectId(toolId)) } })
      .project({ _id: 1 })
      .toArray()
      .then((tools) => tools.map((tool) => tool._id.toString()))),
    ...toolFromConfigs
      .filter((el) => (settings?.tools ?? []).includes(el._id.toString()))
      .map((el) => el._id.toString()),
  ];
  settings.tools = newTools; // Оставляем только валидные id
}
```

## Как инструменты попадают в генерацию

Исходный файл: `src/lib/server/textGeneration/index.ts` (строки 76–87)
```typescript
let tools = model.tools ? await getTools(toolsPreference, ctx.assistant) : undefined; // Получаем активные инструменты
if (tools) {
  const toolCallsRequired = tools.some((tool) => !toolHasName(directlyAnswer.name, tool));
  if (toolCallsRequired) {
    toolResults = yield* runTools(ctx, tools, preprompt); // Вызов инструментов (если нужны)
  } else tools = undefined;                                 // Иначе отключаем инструменты
}
const processedMessages = await preprocessMessages(messages, webSearchResult, convId);
yield* generate({ ...ctx, messages: processedMessages }, toolResults, preprompt);
```

## Вызов инструмента

Исходный файл: `src/lib/server/textGeneration/tools.ts` (строки 195–233, 63–106)

for await (const output of await endpoint({     // Передаём в endpoint список tools

      .filter((call) => call !== undefined) as ToolCall[];

  }

...

  calls.map((call) => callTool(toolContext, tools, call))

## Примечание

- Полный путь конкретного инструмента (например, websearch) и его детализация будут описаны в отдельных файлах по шаблону (поддиаграммы): выбор → подготовка вызова → вызов/ответ → отображение.
